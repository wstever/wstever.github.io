1. iChain Agent 平台（主业）​

2026 年 6 月加入联想 GSC LME，做 AI 应用开发与 Agent 平台建设。

我们面对的家底是十九个核心系统（ECC / APS / MES / WMS / QMS 等）和十条端到端业务流程。iChain 是内部的 Agent 平台，底下的数据底座是 LUDP。我的工作就是在这个底座上，把跨系统的、靠人肉跑腿的流程，织成 Agent 能跑的链。

这是典型的企业级场景：Demo 五分钟，接系统两个月。接口权限、异常分支、数据口径、监控告警，每一项都比写 Prompt 难。具体细节涉及公司内部系统就不展开了，踩坑心得写成了一篇博客，欢迎围观。

2. 公牛排插电商网站​

电商项目负责人，服务公牛、德力西、小米等电器品牌。目前主力推进公牛排插电商网站从 0 到 1：商品体系、渠道对接、客服与订单流，一块一块搭。

排插这个品类看着传统，实则 SKU 杂、规格细、咨询量大——恰好是 AI 客服和数据发挥的地方。

3. Streamlit 短视频生成工具​

基于 Streamlit + win32com SAPI 的短视频生成工具：

  • 输入文案，自动生成配音和字幕分段
  • 字幕节奏可控：最短 1.4s、最长 3.5s，支持慢速 / 正常 / 快速三档（默认正常）
  • 配音开关默认开启，可一键静音出片

界面是 Web 的，内核是本机 SAPI 语音合成——轻量、免费、不依赖云服务，做短视频初稿绰绰有余。

4. 个人办公工作台​

一个单文件的本地工作台，数据只存在本机浏览器：

  • 今日待办（昨天没做完的自动顺延，还记录顺延次数）
  • 灵感速记（标签归类、按标签筛选）
  • 项目跟进（进展 / 下一步 / 卡点，关联待办自动算进度）
  • 每周复盘（每日完成、优先级分布、卡点汇总）
  • 工具集合（Markdown 转 PDF、格式转 PDF、音频一分为二、PDF 瘦身）
  • Skills 管理（嵌入本机 SkillHub）

👉 打开线上版工作台（你看到的是干净模板，我的数据在我本机）

本地源码在 D:\wstever.github.io\personal-toolbox，双击 open-workbench.bat 即可在本机启动，数据都在自己浏览器里。

5. 个人提效工具箱（personal-toolbox）​

本地优先的文件处理 Web 应用，浏览器管界面，本机 Fastify 服务管重活，文件不出本机，断网也能用：

  • PDF 压缩（轻度 / 均衡 / 强力三档，真实对比前后体积）
  • 格式转 PDF（EPUB / OFD 自动识别转换器）
  • Markdown 转 PDF（A4 带页码，中文排版）
  • 大音频一分为二（M4A / MP3 / WAV / AAC / FLAC / OGG）
  • CSV 项目清单 → PNG / HTML 长图

6. 公众号一键排版工具​

写公众号的人的刚需：左边粘 Markdown，右边实时预览微信风格排版，一键复制，直接粘进公众号后台。标题、加粗、引用、列表都按微信生态调过样式。

7. 电商客服数据分析 AI Skill​

面向电器品牌电商的客服数据分析能力，覆盖三类核心数据：

  • 聊天记录：高频问题、情绪波动、响应质量
  • 订单数据：转化路径、异常订单归因
  • 退款数据：退款原因聚类、可挽回损失识别

目标是让运营同学早上打开电脑，昨天的客诉已经归好类、排好序、附上了建议。

8. Skill 知识管理实践​

把"散乱的经验"变成"AI 可调用的知识"的一系列实践：

  • SenseNova-Skills：SenseNova 模型使用的技能封装

内核是一个信念：AI 的价值不在于它多聪明，而在于它多了解你做过的事。
