用 Agent 重构教师工作流

场景全景​

教师的工作流拆开看，有四大块：备课、上课、批阅、分析。每一块都有明确的重复劳动，也都藏着只有老师才能做的判断。

Agent 化的思路不是把老师换掉，而是把每一块里的体力活抠出来交给 AI，判断和关系留给老师。

备课：从零起草到模板生成​

备课最耗时的是"从零起草"：查资料、定目标、设计环节、找例题。这部分 AI 能帮上大忙——按学情给定初稿，按模板生成分层练习。

我的做法是准备一套自己的备课 Skill：输入课文或知识点、班级水平、课时，输出包含教学目标、环节设计、分层练习、互动游戏的初稿。老师的工作从"从零写"变成"审和改"，省下的时间用来做 AI 做不了的事：琢磨这个班这群学生今天的状态。

批阅：结构化判断​

批阅是天然适合 Agent 的环节。客观题对错、步骤分、错因归类，全是规则明确的判断。卷子截图进去，批阅表格出来：每题的得分、每个学生的错因、每个班级的知识点集中度。

关键设计是置信度标记。模糊的字迹、非常规的解法，AI 标出来让人复核，绝不硬判。批阅是教育行为，每个判断都要能追溯。

分析：学情报告​

批阅数据沉淀下来，才是学情分析的原料。Agent 按周生成班级报告：知识点强弱、学生波动、进步与退步名单、需要重点关注的对象。

更进一步是个性化反馈：按每个学生的错法生成反馈草稿，老师修改定稿后发给学生。前面提过，这里的原则不可动摇：AI 出草稿，老师签字。

上课与之后：互动和复盘​

上课环节 AI 能帮的不多，但课前可以生成互动游戏和情境导入。课后，教学反思也可以让 AI 当陪练——把这节课的实录要点丢给它，让它从学生视角挑毛病。

整体架构​

整个工作流的 Agent 化，本质上是一条流水线：

素材进入 → 各环节 Skill 并行处理 → 结构化中间产物 → 老师决策点 → 产出

每个 Skill 只管自己那一段，段与段之间用结构化数据传递。这样某个环节升级（比如换更强的模型）不影响其他环节，老师也能随时在任意决策点接管。

写在最后​

重构教师工作流这一路，最大的体会是：老师的不可替代性，在 Agent 化之后反而更清晰了。AI 把批阅、归类、起草全包了，剩下来的全是"人"的部分——发现某个学生今天情绪不对，判断班级气氛该松还是该紧，在一百份反馈里挑出最值得当面聊的那三个。

这些事，AI 一件都干不了。而以前，老师被体力活挤得没空干这些。
